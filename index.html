Connect your Google Sheet

This uses a small Google Apps Script attached to your own Sheet as a free write-endpoint — no Google Cloud project or API keys needed.

  1. Create or open a Google Sheet.
  2. Extensions → Apps Script, delete any starter code, and paste the script below.
  3. Click Deploy → New deployment → type "Web app". Set "Execute as" to Me and "Who has access" to Anyone.
  4. Copy the Web app URL it gives you and paste it below.
